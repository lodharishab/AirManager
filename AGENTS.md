# AirManager repository rules

The canonical repository is https://github.com/lodharishab/AirManager.git. Contribute to this repository and merge approved changes into its main branch. Never substitute a fork as origin. Before pushing or deploying, verify the remote URL and reconcile main without force-pushing.

Run npm run check, npm run lint, npm test with an isolated .env.test database role, and npm run build. Never run tests or forced schema pushes against production. Follow docs/OPERATIONS.md for deployment and backups. Keep credentials, environment files, database exports, uploads, dependencies, and dist out of Git.

Rivaan has 11 rooms. Unclassified room details and August 26–27 historical stay outcomes remain pending owner verification; do not invent or overwrite them.
